Earth Coordinates

Find any real place on the Earth Worldgen map, the 1:5 Earth on earth.tj. Type a place or a latitude and longitude to get the block to go to.

Find a place

    Latitude and longitude → blocks

    You can also paste both at once, like 48.8584, 2.2945, into either box.

    Arrive high up (Y 600) so you don't land inside a mountain. New land takes a moment to appear.

    Blocks → latitude and longitude

    See this spot on OpenStreetMap

    Map scale (only change this for a server with a different scale)
    The map is a plain latitude/longitude grid: X = longitude × blocks per degree, Z = −latitude × blocks per degree, with 40,075,016.686 ÷ scale ÷ 360 blocks per degree (about 22,264 at 1:5). Place search by Nominatim, © OpenStreetMap contributors.
